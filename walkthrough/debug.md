# Debug the generated code

**Debug** (F5) runs the generated code under your language's VS Code debugger. It stops at the same
node breakpoints, steps node by node and shows pins' values, without opening the generated file.

| Language | Debugger |
|---|---|
| TypeScript, JavaScript | VS Code's own |
| Python | Python Debugger |
| C# | C# |
| C++ | C/C++ |
| Rust | C/C++ on Windows, CodeLLDB elsewhere |
| Java | Debugger for Java |
| Go | Go (Delve) |
| Lua | Lua Debug |
| GDScript | godot-tools |
| Ruby | VSCode rdbg Ruby Debugger |
| PHP | PHP Debug, with Xdebug |

Debug says which extension to install when one is missing.
