# A project to start from

**New Project** writes a small project in the language's usual layout, with an entry point that runs
its first graph, so it runs with or without VS Code.

Start from the **Tour**. It's one graph with:

- a variable, **Total**;
- a **For Loop** that calls a pure function, **Describe**;
- a structure, **Summary**, made and printed;
- a **Branch**;
- a **Test Case** with **Assert Equal**.

Its comment boxes say what to try. It runs in TypeScript, JavaScript, Python, C#, C++, Rust, Java, Go,
Lua, GDScript, Ruby and PHP.

Have a codebase already? **Set Up in This Project** reports what graphs need there, and changes
nothing until you apply a change.
