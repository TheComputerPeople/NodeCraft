# The Codebase Map

The whole workspace, code and graphs, drawn top to bottom, in four views:

- **Architecture:** projects, folders and files, with their imports.
- **Structure:** types and functions, parents above their children.
- **Call flow:** what calls what, from the entry points or any function.
- **Control flow:** one function's flowchart.

A function's box offers **Expose as Node**, and a graph's opens it. The map reads the code and runs
nothing, so it works in Restricted Mode too.
